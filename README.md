# diumi-frontend

디우미 - AI 기반 시니어 디지털 생활 도우미 서비스 프론트엔드

## 기술 스택

Next.js (App Router) · React · TypeScript · Tailwind CSS · Vitest · Playwright

## 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm run format:check
npm run typecheck
npm test
npx playwright install chromium   # 처음 한 번만
npm run test:e2e
```
